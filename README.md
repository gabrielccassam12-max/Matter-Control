# Matter Control (Fabric 1.21.1)

Segure **G** olhando para um bloco do chão para absorver matéria (a barra no canto inferior esquerdo enche e o bloco entra na paleta).
**R** usa o poder selecionado, **X / Z** trocam o poder, **C** troca o material (bloco da paleta) usado para construir.
Receita do Núcleo de Matéria: 4 obsidianas em cruz + diamante no centro. Clique direito para despertar (uma vez só).
Os blocos criados/destruídos voltam ao normal sozinhos. Configuração: config/mattercontrol.json
